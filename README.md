# Student Performance Dashboard - Excel

## Project Overview
This project analyzes student performance data using Microsoft Excel.
The dashboard helps understand student marks, overall performance,
and important patterns in the dataset.

## Tools Used
- Microsoft Excel

## Excel Skills Practiced
- Excel Formulas
- IF / Conditional Logic
- Sorting and Filtering
- Pivot Tables
- Charts
- Dashboard Creation

## Project Goal
To practice data cleaning, analysis, and dashboard creation using Excel
and present student performance in an easy-to-understand format.

## What I Learned
- How to analyze data using Excel
- How to summarize data using Pivot Tables
- How to create charts and dashboards
- How to present insights clearly
